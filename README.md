# Сайт ООО «Топком»

Публичный сайт провайдера для Вышнего Волочка. Заявок, базы и кабинета сотрудника нет: подключение и бизнес идут через телефон.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000.

Проверки:

```bash
npm test
npm run typecheck
npm run lint
npm run build
```

Сборка кладёт статику в `out/`.

## Контент

Тексты и цифры лежат в `content/`.

- Тарифы и допуслуги: `content/tariffs.ts`. Сумма за 30 дней считается в `content/money.ts`.
- Телефоны, адрес, почта `buh@tkvvnet.ru`, цены монтажа: `content/contacts.ts`.
- Оплата: `content/payments.ts`. Адрес личного кабинета зафиксирован как `http://тквв.рф`.
- Вопросы: `content/faq.ts`.
- Лицензии: `content/documents.ts`.
- Политика и согласие: `content/legal.ts`. Версия согласия указана в `consentVersion`.
- Объявление о работах: `content/announcement.ts`. По умолчанию выключено. Чтобы показать, поставьте `isEnabled: true`, заполните `territory`, `text` и `updatedAt`.

Почта `buh@tkvvnet.ru` не подписывается как техподдержка.

## Заявки

Формы нет. Кнопка «Выбрать тариф» ведёт на `/connect/?tariff=<id>` из белого списка. Адрес и телефон в ссылку не попадают.

## Индексация

Пока `NEXT_PUBLIC_SITE_URL` пустой или локальный, сайт закрыт от индексации. Перед публичным доменом задайте адрес в `.env` и пересоберите проект. Пример есть в `.env.example`.

## Деплой

Сайт открывается на `топком.site` с того же VPS, что maxima-consulting.ru. Конфиг того сайта не меняется.

- Код на сервере: `/opt/topkom/TKVV`
- Статика: `/var/www/topkom/static`
- После push в `main` GitHub Action запускает `deploy/deploy.sh`
- Ручной запуск на сервере: `bash /opt/topkom/TKVV/deploy/deploy.sh`

`NEXT_PUBLIC_SITE_URL` на выкладке не задаётся, поэтому индексация остаётся закрытой.

## Продакшен

Перед открытием индексации сверить:

- БИК и расчётный счёт
- график офиса
- статус лицензий
- личный кабинет с домашней сети и при отрицательном балансе
- шаги оплаты в приложении Сбера
- публичный домен и логотип
- применимость политики и уведомление Роскомнадзора
