# Топком — интернет-провайдер

Профессиональный русскоязычный сайт ООО «Топком» для Вышнего Волочка и Вышневолоцкого городского округа. Интерфейс собран на React, TypeScript, Vite, Express, tRPC и Drizzle.

## Запуск

```bash
pnpm install
pnpm dev
```

Сервер слушает `PORT` (по умолчанию `3000`). Для production-проверки используйте `pnpm build` и `pnpm start`. Типы проверяются командой `pnpm check`, тесты — `pnpm test`.

## Где обновлять контент

Тарифы, территории, дополнительные услуги, способы оплаты, FAQ, реквизиты, документы и объявления о работах находятся в `client/src/data/site.ts`. После изменения данных нужно обновить `client/public/sitemap.xml` и SEO-метаданные, если меняются публичные маршруты или домен.

## Заявки

Форма `/connect` и форма для бизнеса `/business` передают на сервер только поля из интерфейса: населённый пункт, улицу и дом, телефон, необязательные имя/тариф и название организации для бизнеса. Сервер проверяет схему и согласие версии `v1.0`, ограничивает частоту, проверяет повторную заявку по телефону и адресу за последние 24 часа и записывает заявку в таблицу `connection_requests`. Номер заявки создаётся после успешной записи. При недоступной БД клиент не показывает ложный успех и предлагает позвонить в поддержку.

Перед миграцией таблицы заявок используйте `pnpm db:push` в согласованной среде. Управляемая БД общая для разработки и публикации: не добавляйте тестовые персональные данные без согласования и не выполняйте разрушительные SQL-операции.

## Платежи

Публичная страница `/pay` содержит ровно два внешних способа: ЛК «Топком» и СберБанк Онлайн. Переход происходит только по нажатию пользователя. Финальные URL, протокол ЛК, реквизиты, комиссия и срок зачисления требуют проверки ответственными. Конфигурационные подсказки находятся в `.env.example`; текущие публичные значения и инструкции централизованы в `client/src/data/site.ts`.

## Объявления о работах

Текущий блок `worksNotice` на главной — ручное объявление с территорией и временем обновления. Он не является автоматическим статусом сети. Обновляйте или скрывайте его только после подтверждения содержания.

## До публикации

Нужно подтвердить URL и протокол ЛК, ссылку Сбера, банковские реквизиты, дату тарифов и территории, стоимость и сроки монтажа, политику и согласие на обработку ПДн, хранение заявок в РФ, публичный домен, логотип, контакты, график, документы и лицензии. Production-публикация без отдельного разрешения не выполняется.
